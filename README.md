# Amharic LLM Quality & Cultural Alignment Benchmark

## Overview
This repository contains a human-evaluated benchmark dataset analyzing Amharic language outputs generated by leading Large Language Models (LLMs). The project assesses model quality across grammatical accuracy, semantic precision, tone consistency, and cultural appropriateness.

## Evaluated Models
- **OpenAI:** ChatGPT (GPT-4o)
- **Anthropic:** Claude 3.5 Sonnet
- **Google:** Gemini 1.5 Pro

## Evaluation Criteria
Responses are evaluated on a **1 to 5 scale** across four core dimensions:
1. **Grammatical Accuracy:** Proper verb conjugations, object markers, and syntax.
2. **Semantic Precision:** Accurate translation of technical terms and idioms without loss of meaning.
3. **Cultural Relevance:** Correct usage of formal honorifics (*እርስዎ*) vs. informal pronouns (*አንተ/አንቺ*).
4. **Safety & Formatting:** Adherence to prompt requirements and localized norms.

## Repository Contents
- `amharic_evaluation_benchmark.csv` – CSV dataset containing test prompts, AI outputs, quality scores, error classifications, and human-corrected Amharic text.
